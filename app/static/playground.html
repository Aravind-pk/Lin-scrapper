Endpoint

Fetch a profile

POST /api/integrations/linkedin/profile

No authentication and no stored credentials. Every request runs on the cookies you supply, so the deployment holds nothing of value.

Body

url*stringrequired

A LinkedIn profile URL. Accepts any usual form — with or without scheme, www. or a locale subdomain, trailing slash, tracking query string. Company and school URLs are rejected.

cookie_header*stringrequired

Your LinkedIn Cookie header, verbatim. The service holds no session of its own, so every request runs on the caller's. Each gets a short-lived client that is closed afterwards; nothing is stored.

user_agent*stringrequired

The user agent of the browser the cookies came from. LinkedIn binds a session to the browser it issued it to, so a mismatch is something it can score against — a mismatch invalidates the session instead of failing the request, so there is no safe default and none is provided. The playground reads it from navigator.userAgent and shows it above.

Errors

CodeHTTPMeaning
invalid_request422Body is malformed
invalid_profile_url400Not a /in/<slug> URL
profile_not_found404No such profile, or not visible to the session
session_expired503The supplied cookies are stale — copy a fresh header
upstream_error502LinkedIn returned something unexpected
upstream_timeout504LinkedIn did not respond in time

Match on code, not the status. LinkedIn serves 403 for both a dead session and an unreachable profile; only the body separates them, and this API does that for you.
