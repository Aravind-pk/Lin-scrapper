LinkedIn Profile API

Paste a profile URL and your LinkedIn cookies. Returns structured JSON.
Your cookie header is a live account credential. It is sent in the request body over HTTPS, never in the URL, and is not stored by this page or logged by the server — only cookie names reach the logs. Use this only on a deployment you trust. Requests carry this browser's user agent so they match the session LinkedIn issued it to.
DevTools → Network → any linkedin.com request → Copy as cURL, then everything after Cookie:. Leave blank to use the server's own session.
